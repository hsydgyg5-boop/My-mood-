صدى العراق — حزمة نشر مخففة

الإصدار التقني: 1.6.88
إصدار الواجهة: 2.62

ما الذي تغيّر؟
- قوائم الخدمات تُعرض على دفعات من 80 عنصرًا بدل إنشاء القائمة كاملة دفعة واحدة.
- أزيلت مراقبة عامة كانت تعيد تهيئة إدارة الخدمات مع تغييرات الصفحة الاعتيادية.
- حُذف ملف api-addon.js المكرر من تحميل الصفحة.
- حُذفت سجلات الإصدارات والاختبارات القديمة من حزمة النشر؛ أُبقي اختبار فحص سريع واحد.
- حُفظت ملفات تشغيل الخادم والأمان والإشعارات والصور المضمّنة اللازمة.

تشغيل محلي:
1) استخدم Node.js 22 أو أحدث.
2) نفّذ: npm install
3) نفّذ: npm test
4) نفّذ: npm start
5) افتح المنفذ الذي يظهر في سجل التشغيل.

النشر على Railway:
- ارفع ملفات هذه الحزمة إلى المشروع الموجود ثم انشرها بالطريقة المعتادة.
- أبقِ متغيرات Firebase ومفاتيح الخدمات السرية في Variables ولا تضعها في ملفات عامة.
- لا تغيّر مسار الـ Volume أو متغير SADA_DATA_DIR/DATA_DIR أثناء التحديث.
- الخادم ينشئ ملفات JSON المحلية اللازمة تلقائيًا عند التشغيل؛ لم نضع نسخًا فارغة كثيرة منها داخل ZIP حتى تبقى الحزمة مرتبة.
- لا تستبدل قاعدة بيانات الإنتاج بملفات البيانات المحلية الافتراضية.

التحقق:
- npm test يفحص صياغة الخادم و91 كتلة JavaScript مضمّنة وتوافق رقم الإصدار.
- اختبارات التطوير الكاملة اجتازت في بيئة العمل، باستثناء تعارض مؤقت في اختبار آسياسيل عند التشغيل المتوازي؛ نجح الاختبار عند تشغيله منفردًا.
- لا يعني ذلك أن النشر على استضافة الإنتاج قد تم؛ يجب نشر الحزمة في حسابك والتأكد من /api/health ومراجعة التنقل من الهاتف.
