# مزاجي 2026 — نسخة آمنة للبيانات

هذه النسخة مخصصة لتحديث كود الموقع فقط، مع الحفاظ على بيانات المستخدمين والملفات الموجودة في Railway Volume.

## التخزين الدائم
- يجب ربط Railway Volume بالخدمة على: `/data`
- قاعدة البيانات: `/data/db.json`
- ملفات المستخدمين: `/data/USERS/`
- النسخ الاحتياطية: `/data/backups/`
- الكود لا يحتوي قاعدة بيانات المستخدمين القديمة.
- عند وجود `/data/db.json` يتم استخدامها كما هي ولا يتم استبدالها بملف من GitHub.
- عند كل تشغيل يتم إنشاء نسخة احتياطية غير مدمرة من قاعدة البيانات الحالية.

## مهم
لا تستخدم Wipe Volume ولا تحذف الـVolume.

## متغيرات Railway
ضع الأسرار في Variables، وليس داخل GitHub:
- BOT_TOKEN
- BOT_USERNAME
- MAZAGI_DATA_DIR (اختياري؛ اتركه `/data` إذا كان Volume مركباً هناك)

## استعادة مسارات الملفات
البرنامج يحاول تلقائياً نقل/ربط ملفات السيرفرات القديمة إلى `/data/USERS/...` إذا كانت الملفات القديمة ما زالت موجودة داخل الحاوية أو في المسار السابق، بدون حذف المصدر.
