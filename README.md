# مزاجي 2026 — نسخة آمنة للبيانات

هذه النسخة مخصصة لتحديث كود الموقع فقط، مع الحفاظ على بيانات المستخدمين والملفات الموجودة في Railway Volume.

## التخزين الدائم
- استخدم **الـRailway Volume الموجود حالياً** والمربوط على `/data`.
- قاعدة البيانات: `/data/db.json`
- ملفات المستخدمين والسيرفرات: `/data/USERS/`
- ملفات PHP: `/data/php_files/`
- النسخ الاحتياطية: `/data/backups/`
- عند وجود `/data/db.json` يتم استخدامها كما هي ولا يتم استبدالها بملف GitHub.
- لا تنشئ Volume جديداً أثناء التحديث، ولا تحذف الـVolume الحالي.

## مهم جداً
هذه النسخة تغيّر **كود المنصة فقط**؛ بيانات `/data` تبقى في الـVolume الدائم.
لا تستخدم Wipe Volume ولا Delete Volume أثناء التحديث.

## متغيرات Railway
ضع الأسرار في Variables، وليس داخل GitHub:
- BOT_TOKEN
- BOT_USERNAME
- MAZAGI_DATA_DIR (اختياري؛ اتركه `/data` إذا كان Volume مركباً هناك)

## استعادة مسارات الملفات
البرنامج يحاول تلقائياً نقل/ربط ملفات السيرفرات القديمة إلى `/data/USERS/...` إذا كانت الملفات القديمة ما زالت موجودة داخل الحاوية أو في المسار السابق، بدون حذف المصدر.


## تحديث واجهة الملفات
- كل زر ملف يظهر بعرض كامل وفي سطر مستقل على الهاتف والكمبيوتر.
- تم إزالة CSS المتعارض الذي كان يضغط الأزرار ويقصها.
- دعم أفضل للملفات داخل المجلدات بعد فك ZIP.
- لا يوجد أي كود يقوم بتصفير أو استبدال قاعدة البيانات الحالية.


## دعم المنصة
- Python: تشغيل تلقائي للمكتبات، ودعم Flask/FastAPI عبر Gunicorn مع فحص حقيقي للمنفذ.
- Node.js: تثبيت dependencies من package.json وتشغيل start عند توفره.
- PHP: تشغيل PHP built-in server إذا كان PHP مثبتاً على بيئة الاستضافة.
- HTML/CSS/JS: تشغيل المواقع الثابتة تلقائياً عبر خادم HTTP.
- لا تظهر حالة "يعمل" للموقع إلا بعد التأكد أن العملية ما زالت حية وأن الموقع استجاب فعلياً.
- لوحة الإدارة تعرض جميع سيرفرات المستخدمين وتتيح تنزيل ملفات السيرفر كاملة.
- تمت إضافة زر "حذف جميع الملفات" داخل قسم ملفات السيرفر، مع تأكيد مزدوج.
