إصدار إصلاح أزرار الملفات 2026

تم فحص app.py بنجاح بـ Python compile.
تم فحص JavaScript المضمن في index.html بنجاح بـ Node syntax check.

أزرار الملفات تستخدم event delegation بدلاً من onclick داخل HTML الديناميكي:
- تعديل
- تبديل الملف
- تنزيل
- تغيير الاسم
- فك الضغط
- حذف الملف

لا يوجد في هذا الإصدار أي كود لمسح /data أو إنشاء قاعدة بيانات فوق قاعدة موجودة.
قاعدة /data لها الأولوية دائماً عند التشغيل.
