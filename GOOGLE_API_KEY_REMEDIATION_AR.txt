إصلاح تنبيه مفتاح Google/Firebase API
====================================
أزيلت قيمة مفتاح Firebase Web API المضمّنة من server.js. يقرأ التطبيق الآن
المفتاح من متغير البيئة FIREBASE_WEB_API_KEY فقط.

قبل النشر على Railway:
1) افتح Variables للخدمة وأضف FIREBASE_WEB_API_KEY بقيمة المفتاح الحالي الذي تستخدمه.
2) إذا كان المفتاح الذي ظهر في تنبيه GitHub حقيقيًا أو سبق نشره، أبطله/دوّره من Google Cloud Console ثم استخدم المفتاح البديل.
3) قيّد المفتاح بحسب واجهات API المطلوبة، وراجع إعدادات Firebase Security Rules. مفتاح Firebase Web API ليس بديلًا عن قواعد الأمان.
4) أعد النشر وافحص Deploy Logs. إذا لم تضبط المتغير، قد تتعطل وظائف Firebase التي تحتاج المفتاح إلى أن تضبطه.

ملاحظة: إزالة المفتاح من الملف الحالي لا تمحو القيمة من تاريخ Git السابق؛ استخدم خيار إبطال/تدوير المفتاح، ولا تعتمد على حذف النص وحده.
